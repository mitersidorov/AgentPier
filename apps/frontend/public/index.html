Connect ChatGPT to AgentPier

          
Setup and first steps

        

        

          
        

      

      

        

          Important: ChatGPT cannot connect directly to localhost:3100. AgentPier
          currently runs locally and no Secure MCP Tunnel is configured.
        

        
Connect in ChatGPT

        
    
          
  1. Start AgentPier on this Mac with docker compose up -d.
    2. 
          
  2. 
            Make AgentPier reachable through an available Secure MCP Tunnel. The tunnel must point to
            http://localhost:3100/mcp. Do not expose the local service publicly without a protected
            connection.
          
    3. 
          
  3. 
            Configure the tunnel in a client/workspace that supports remote MCP. Follow that client's current setup
            instructions; AgentPier does not control or verify the client's GUI.
          
    4. 
          
  4. After connecting, call AgentPier MCP tools from the client to list or register a project.
    5. 
        

        

          Full write-capable custom MCP access depends on your ChatGPT plan and workspace permissions. OpenAI currently
          documents full MCP for Business and Enterprise/Edu; Pro supports read/fetch access. See the
          official OpenAI setup guide.
        

        
Use the project workflow

        
    
          
  1. 
            Register a project with its Mac folder using register_project; add applications and
            repositories with manage_applications.
          
    2. 
          
  2. 
            Start read-only discovery with analyze_task; review the saved findings using
            get_analysis_results.
          
    3. 
          
  3. 
            Discuss a draft with the user. Save it with save_plan and call approve_plan only
            after explicit user approval.
          
    4. 
          
  4. 
            Run execute_task. Follow progress and agent questions with get_task_status and
            get_agent_messages; respond with send_agent_message.
          
    5. 
          
  5. 
            Show the finished changes with get_task_results. Push or publish only after a separate user
            decision.
          
    6. 
        

        
Connect local Codex CLI

        
For local MCP access without ChatGPT, run this on the Mac:

        
codex mcp add agentpier --url http://localhost:3100/mcp

        

          ChatGPT MCP uses Streamable HTTP. The Manager connects to Codex app-server separately over WebSocket.
